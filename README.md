# Зборівська громада — вебзастосунок (PWA)

Незалежний демонстраційний інформаційний застосунок для жителів Зборівської громади. Працює в браузері iPhone та Android; можна додати на головний екран.

## Що працює
- Головна сторінка, вибір населеного пункту та збереження адреси на пристрої.
- Посилання на офіційний графік Тернопільобленерго.
- Локальний **демонстраційний** чат, повідомлення не передаються іншим людям.
- Розділи оголошень, профілю, інсталяційний PWA manifest і service worker.

## Що НЕ працює без додаткового сервера
- Автоматичне завантаження графіків від Тернопільобленерго.
- Справжній чат між телефонами, SMS-реєстрація, push-сповіщення.
- Адмінпанель, захищена серверною авторизацією.

Не рекламуйте цю демонстрацію як готовий сервіс реальних графіків або чатів.

## Як розмістити з iPhone: GitHub → Cloudflare Pages
1. Створіть **новий репозиторій** на github.com (наприклад, `zboriv-gromada`).
2. На сторінці репозиторію виберіть **Add file → Upload files** та завантажте файли **з кореня цього архіву**: `index.html`, `manifest.webmanifest`, `icon.svg`, `sw.js`, `README.md`, `_headers`, `.gitignore`. Якщо Safari не дозволяє вибрати багато файлів, можна завантажити їх по одному. GitHub не розгортає ZIP автоматично в репозиторій — архів спочатку треба розпакувати у «Файлах» iPhone.
3. В Cloudflare Dashboard відкрийте **Workers & Pages → Create → Pages → Connect to Git**, авторизуйте GitHub та оберіть репозиторій.
4. Налаштування збірки: **Framework preset: None**, **Build command: (порожньо)**, **Build output directory: /** (корінь репозиторію; якщо інтерфейс вимагає значення, вкажіть `.`).
5. Натисніть **Save and Deploy**. З'явиться адреса `*.pages.dev`.
6. Подальші зміни файлів у гілці, підключеній до Pages, автоматично публікуватимуться.

> Якщо Pages не приймає корінь як output directory, використайте **Direct Upload** архіву статичних файлів, або перенесіть ці файли в папку `public` і встановіть Build output directory: `public`.

## Конфіденційність і безпека
- Не додавайте до GitHub паролі, приватні API-ключі, сервісні токени чи SMS-секрети.
- Для майбутніх чатів та адміністративних дій необхідні серверні перевірки доступу.
- Адреса та тестові повідомлення зберігаються локально в браузері.

## Локальна перевірка
Це статичний сайт без npm-залежностей. Для коректної перевірки service worker потрібен HTTPS або localhost.
